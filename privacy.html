Privacy policy

Last updated: October 27, 2026

Alfred Analytics is a private tool used only by the owner of the YouTube channel @hrp.aisolutions to read that channel's own statistics.

What data the tool reads

With the owner's permission, through Google sign in, the tool reads YouTube channel and video statistics: views, likes, comments, watch time, average view duration, subscribers gained and audience retention. It uses read only access (youtube.readonly and yt-analytics.readonly).

How the data is used

The statistics are used only to make reports for the channel owner about how the channel's videos perform.

Where the data is kept

Reports are kept on the owner's own computer and in the owner's private storage. The data is not sold, shared with anyone else or used for advertising.

Google user data

Alfred Analytics' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

How to remove access

Access can be removed at any time at myaccount.google.com/permissions. Stored reports can be deleted on request.
